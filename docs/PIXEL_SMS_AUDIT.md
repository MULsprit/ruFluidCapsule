# Pixel 通知与验证码修复（1.1.2）

本版本在 Pixel 11 Pro XL（Android 17 / API 37）验证通知构造和历史导出。Pixel 使用原生实时通知与通知卡片，界面统一采用“实时通知”等表述。

## 验证码解析

修复中文紧贴数字的边界、繁体验证码与一次性密码，并补充有明确认证上下文的中文和英文模板，包括 SMS Code、NetCode、品牌插入的验证模板、德文短信验证与分段六位码。

明确模板只在原评分解析器返回 None 时兜底，不覆盖已有成功结果或歧义判断。多个不同候选返回歧义；URL、固定客户编号、付款机构编号、促销码和取货码有独立负例。

私有语料逐条审阅和离线重放确认原有成功结果保持一致，已确认的漏识别得到修复。原始短信、验证码、通知日志、设备连接信息及逐条标注不随源码发布；仓库测试使用合成样本。离线重放不能证明过去的通知曾被监听器收到，也不能替代新短信端到端验证。

## 通知与历史

- 默认短信没有可靠验证码且不在普通通知白名单时，历史明确记录跳过原因，避免一直停留在“正在处理”。
- “已提交展示队列”与系统实际显示区分，避免将入队误称为已经展示。
- 新增受 DUMP 权限保护的分页历史导出，包含完整正文和处理原因。
- 分页使用固定 ID 插入上界和输出字节预算；单条超出预算时明确报错，不静默截断。
- 活跃记录仍可能更新或删除，因此插入上界不是数据库一致性快照。
- 历史保留策略继续支持永久保存；升级沿用用户已有设置，不重置为七天。

Pixel 图标提示与头像选择详见 [Pixel 适配](PIXEL.md)，导出用法见 [CLI](CLI.md)。

## 验证范围

92 项 JVM 测试通过；Android lint、签名 Release 构建通过。Pixel 真机 4 项仪器测试覆盖头像优先级、缺失头像时不借用历史发送者、通知图标提示与隐私版本，以及历史分页、插入上界和完整 Unicode 正文。

未进行新的真实短信或 RCS/MMS 接收链路测试；原有 OPPO 真机套件未在本次重跑。正式升级沿用包名、签名与历史数据库版本，通过覆盖安装保留应用数据。
