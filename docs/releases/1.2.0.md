# FluidCapsule 1.2.0

## 中文

- 识别更多验证码措辞，包括 UNiDAYS 一次性密码和“登录代码／登入代码”。
- 对明确的邮箱、账户或身份验证请求识别相邻的验证网址，并在胶囊中提供“打开验证链接”。普通链接、已完成验证和不相关链接继续过滤；无可见网址时可打开来源通知。
- 新增官方 GitHub 规则订阅。进入应用时检查已签名清单，有更新时仅在应用内提示；点击后才下载并安装规则包。“规则”页面可关闭自动检查、手动检查或恢复内置规则。
- 通知内容仍在设备本地解析，不会随规则检查上传。

## English

- Recognizes additional OTP wording, including UNiDAYS one-time passcodes and Chinese login-code labels.
- Offers **Open verification link** for an explicit unfinished verification request with one nearby URL. Ordinary, completed, and unrelated links remain filtered; messages without a visible URL can open their source notification.
- Adds an official GitHub rule subscription. The app checks a signed manifest on foreground entry and prompts inside the app; rule packs download and install only after a tap. The Rules page can disable automatic checks, check manually, or restore bundled rules.
- Notification content remains on device and is not uploaded during rule checks.

The version 1 rule pack matches the bundled behavior. The rule feed can extend approved wording, while algorithm and UI changes continue to ship through APK releases.
